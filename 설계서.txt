인터맵(가제) - 지도 + SNS
개요 : 네이버지도 + 인스타그램을 혼합시킨 어플이고, 먼저는 음식집을 시작으로 확장함
내용
	- 네이버지도 상 음식집들이 있고 음식집 안에는 서로 이웃을 맺은 지인들의 후기를 볼 수 있다.
	- 후기 밑 댓글란도 있다
레이아웃
----------------------------------
| 맵필터       인터맵              | -- 앱 이름
|   사람이름 사람이름 사람이름       | -- 스토리(24시간 내 작성된 친구들 후기)
|                                | -- 뒷배경에 네이버지도
|                                | -- 맵필터는 친구 그룹 필터
|                                | -- 친구 그룹마다 지도에 표기되는 DOT 색상이 다름(겹치면 사용자의 SORT 우선순위가 높은거가 나옴)
|                                | -- 특정 음식집을 클릭하면 음식집 정보 및 이웃의 평점 및 메뉴를 확인할 수 있고 하단에 슬라이드 영역으로 이웃들의 후기를 볼 수 있고 더 하단에는 댓글쓰는 공간이 있음
|                                | -- 약속잡기 기능(음식집을 클릭한 후 약속잡기 버튼을 클릭하고 친구들을 설정하면 약속을 잡을 수 있다.)
